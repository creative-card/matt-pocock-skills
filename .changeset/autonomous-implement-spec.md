`implement-spec` runs unattended. It dispatches each implementer at the model and effort its ticket's complexity pair maps to, and helpers at the smallest model that does the job, pausing on a usage limit instead of downgrading. It grills `ready-for-human` tickets against a proxy subagent that answers as the user would from their memory, wiki and ADRs, then moves them to `ready-for-agent`. It loops the user in only for a critical decision (hard to reverse, outward-facing, security-sensitive, against a recorded decision, or changing the plan) and lists the proxy's unsourced guesses in the final report. `chief-of-staff` follows the same rules and files each user answer in its wiki so the proxy can give it next time.
